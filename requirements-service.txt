# Self-contained deps for running service.py (the video-stream analysis
# service). Deliberately NOT layered on top of requirements.txt: that file
# is a raw `pip freeze` of someone else's conda environment (246 lines,
# includes unresolvable local conda build paths like
# `archspec @ file:///home/conda/...`) and fails outright under plain pip
# install -- confirmed by trying it. This file lists only what this repo's
# code actually imports (facetracking.py/obd.py/vad.py/service.py), pinned
# loosely (compatible-release, not exact) so pip can resolve current
# wheels rather than someone else's frozen-at-a-point-in-time versions.
#
# Install: pip install -r requirements-service.txt
